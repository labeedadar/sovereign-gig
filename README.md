# Sovereign-Gig

**Sovereign-Gig** is a private, client-side toolkit designed for independent freelancers to manage direct-to-client relationships without platform fees or intermediaries.

## 🚀 Features

- **AI Signal Filter:** Analyze job descriptions and inquiries to detect quality, budget alignment, and payment intent.
- **Bank & Card Portal:** A professional interface to share bank transfer details and direct payment links (Stripe/Wise).
- **Web3 Escrow:** An optional, trust-less payment layer for crypto-native clients using Ethereum-based smart contracts.
- **Privacy-First:** All processing happens in your browser. No data is stored on external servers.

## 🛠️ Setup & Deployment

1. **Clone this repository.**
2. **Open `src/app.js`** and customize the `freelancerProfile` object with your tech stack and preferences.
3. **Open `index.html`** and update the placeholder bank details with your own.
4. **Host for FREE** using GitHub Pages:
   - Push this repo to GitHub.
   - Go to **Settings > Pages**.
   - Select the `main` branch and `/root` folder.
   - Your dashboard is now live and accessible on Mobile!

## 🛡️ Security

- The Web3 portal requires a browser-based wallet like **MetaMask**.
- For mobile use, open the hosted URL inside the **MetaMask Mobile App Browser**.
